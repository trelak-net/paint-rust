Getting started
Create a new image or open a file from the File menu. Drop files onto the window to open them in separate tabs. Use Window to switch documents, or Ctrl+Tab and Ctrl+Shift+Tab.

Painting and colors
Choose a tool from Tools. Left-click paints with the primary color; right-click uses the secondary color where supported. X swaps colors. Brush options include size, hardness, opacity and antialiasing. Enable Blend color to use the selected paint blend mode. Ctrl+click sets the Clone stamp source before painting.

Selections and layers
Use rectangle, ellipse, lasso, polygon or color selection to restrict edits. Selection options can add, subtract, intersect or replace. Layers has commands to add, duplicate, import, reorder and merge layers. Layer properties changes the name, opacity and blend mode. Hidden layers are retained in project files.

Saving your work
Use PRUST or PDN to retain editable layers. Saving to a raster format requires flattening confirmation; Undo restores the layered document after saving. Export writes the visible image without replacing the current document. Preview the encoded result before writing. JPEG and GIF can lose detail; JPEG/BMP remove transparency. GIF opens and saves one frame.

Color profiles
Supported embedded RGB/grayscale profiles are converted to sRGB when opening raster images. PNG, JPEG, WebP and TIFF exports embed sRGB. Other raster exports are untagged. Source author, location and comment tags are omitted from raster exports. EXIF orientation is applied to the image.

Navigation and panels
Use the Zoom or Pan tools, or hold Space to pan temporarily. Ctrl+B fits the image; Ctrl+Shift+B fits the selection. View controls the theme, pixel grid, rulers and panel visibility. Small windows use scrollable sidebars; enlarging restores a chosen floating layout.

Previews and recovery
Adjustments, effects and text show a preview. Apply commits the change; Cancel or Escape returns to the previous image. Undo/Redo navigates edits. Unsaved recovery copies can be restored when offered at startup. Saving a project remains the way to keep a deliberate copy of your work.

Transform a selection boundary
Choose Selection > Transform selection boundary, or press Ctrl+Alt+M, to rotate,
scale, flip or move only the selected area boundary. The preview keeps image
pixels unchanged. Apply or Enter accepts it; Cancel or Escape restores the
original selection. Use Free transform pixels when the image content should move.

Reuse a selection shape
Copy selection geometry (Ctrl+Alt+Shift+C) puts its shape on the clipboard as JSON
text. Paste selection geometry can replace, add to, subtract from or intersect
an existing selection; XOR keeps areas covered by only one of the two shapes.
Ctrl+Alt+Shift+V pastes with Replace. This copies the boundary rather than image
pixels, so it can be reused on another layer or document.

Undo selections
Selection changes can be undone and redone alongside image edits. Selecting,
deselecting, moving or transforming a selection boundary does not make a saved
image dirty. Press Ctrl+D to deselect; Ctrl+Shift+A is also supported.

Choose a paste destination
Ctrl+V pastes into the active layer. Ctrl+Shift+V creates a new layer, and
Ctrl+Alt+V creates a new image sized to the clipboard. Pasted pixels are selected
and the Move tool activates. Backspace fills the selection with primary color;
Shift+Backspace uses secondary color.

If pasted pixels extend beyond the canvas, choose Expand canvas to keep them all,
Keep canvas to clip them, or Cancel. Expansion and paste undo together.

Zoom in with Ctrl++ (or Ctrl+=), out with Ctrl+-, and return to actual size
with Ctrl+0. The View menu offers the same commands.

Clone across layers
Ctrl+click sets the source layer and position. Select another layer to paint there
without changing the source. Sample merged image reads the visible composite.
Source samples stay frozen during each stroke. Deleting the source layer requires
undoing its deletion or choosing another source.

Recover several documents
Use Recover all into separate tabs in the recovery window. Existing open work is
kept. Failed snapshots remain available for individual retry or discard; other
snapshots continue loading. Cancel stops the remaining queue. Recovered documents
are unsaved and need a new save destination. Original tab order and view positions
are not restored yet.

DDS textures
Open reads the top surface of supported RGB/RGBA and BC1/2/3 textures. Export
saves a single uncompressed RGBA8 surface. Mipmaps, cube maps and texture arrays
are not preserved; keep the source file when editing texture assets.
