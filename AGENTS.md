# Project conventions

- Write source comments, documentation and commit descriptions in English.
- Commit each completed, validated change in this repository.
- Every commit message must include the trailer `Generated-by: OpenAI Codex`.
- Keep application artwork original to this project, or use external artwork only
  under MIT or Apache-2.0. Record its source URL, version, author, license and
  modifications, and preserve required notices.
- Project-authored code and artwork use `MIT OR Apache-2.0`; external components
  retain their own licenses.
- Preserve readable labels, keyboard access and light/dark theme support when
  modifying the interface.
