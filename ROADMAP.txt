Development roadmap
===================

[x] Desktop shell, original artwork and license provenance.
[x] Raster drawing, erasing, fill, color sampling and transaction history.
[x] Editable layers and lossless project persistence.
[x] Lines, rectangles and ellipses with cancellable previews.
[x] Rectangular selections, selected-area operations and crop.
[x] Image/canvas resizing, rotation and mirroring.
[x] Clipboard image copy/cut/paste.
[x] Import image files and project composites as layers.
[x] Raster text with editable preview.
[x] Move/copy selected pixels and move selection bounds.
[x] Elliptical selections with masked editing, clipboard and movement.
[x] Background selection union, subtraction and intersection with explicit empty masks.
[x] Polygon selections with editable point input and even-odd coverage.
[x] Numeric free transforms of selected pixels with cancellable previews.
[x] On-canvas translation, scaling and rotation handles with Shift constraints.
[x] Eight layer blend modes with project persistence.
[x] Lossless visible-image flattening with complete layer restoration on undo.
[x] Brightness/contrast, saturation, grayscale, sepia and box blur previews.
[x] Linear and radial gradients.
[x] Pixelation and posterization with cancellable previews.
[x] Sharpening and separate menus for adjustments and spatial effects.
[x] Background recovery snapshots and interrupted-session recovery.
[x] Background open/save/export/import/recovery with guarded completion.
[x] Cooperative cancellation of image/project loading, import and recovery.
[x] Background geometry computation with history-preserving publication.
[x] Cancellable resize, canvas resize, rotation, mirroring and background crop.
[x] Background canvas compositing with coalescing and stale-result protection.
[x] Incremental changed-region compositing and partial texture uploads.
[x] Cooperative cancellation of project saving and raster export.
[x] PNG and lossless WebP raster export with transparency.
[ ] Large-document performance and cancellation of remaining long operations.
[x] Linux user-local launcher, icons, MIME registration and installation helper.
[x] Native accessibility bridge and explicit palette/layer/canvas labels.
[x] Pinned Linux dependency and standard-library notices with consistency checks.
[x] Cancellable background flood fill, flattening, color inversion and pixel deletion.
[x] Large-image CPU measurements and non-starving active-stroke previews.
[x] Retain undo beyond the RAM budget using private temporary files.
[x] Store and restore disk-backed history outside the UI thread.
[x] Compress temporary history streams losslessly to reduce storage volume.
[x] Share unchanged buffers across disk history states.
[x] Native Linux release archive, checksums and isolated installation validation.
[ ] Deferred until all other roadmap tasks are complete: resolve AT-SPI runtime
    integration issues and perform the full screen-reader workflow audit.

The AT-SPI runtime audit is intentionally deferred and does not block other
implementation or distribution-validation work. Existing accessibility labels and
the native bridge remain in place; full screen-reader support is not yet verified.

Each completed increment receives regression checks and its own commit. Keep the
source and artwork self-contained; preserve project files and unsaved user edits.
